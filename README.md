# RAG Assistant 📄🤖

Чат-бот с искусственным интеллектом для работы с PDF-документами. 
Проект использует архитектуру **RAG (Retrieval-Augmented Generation)**: система находит релевантные куски текста в документе и передает их языковой модели для формирования точного ответа.

## 🛠 Стек технологий
- **Python**
- **FastAPI** — бэкенд для обработки запросов.
- **Streamlit** — интерактивный веб-интерфейс (фронтенд).
- **ChromaDB** — векторная база данных для хранения эмбеддингов.
- **Docker & Docker Compose** — контейнеризация и запуск одной командой.
- **LangChain** (или другая библиотека для работы с LLM) — оркестрация RAG-пайплайна.

## 🚀 Функционал
- Загрузка PDF-документов.
- Разбиение текста на чанки (фрагменты) и создание эмбеддингов.
- Сохранение эмбеддингов в ChromaDB.
- Поиск наиболее релевантных фрагментов по вопросу пользователя.
- Генерация ответа на основе найденного контекста.
